# Glossary

FeedMe turns a web page into Markdown of its main body and hands it to an LLM; signed-in users can keep converted articles in their account.

**저장한 글**:
A snapshot of one conversion (title, author, published date, site, URL, Markdown body) that a signed-in user chose to keep, frozen at save time. Each account keeps at most one per URL; saving the same URL again replaces it.
_Avoid_: 북마크, 변환 기록, 히스토리
