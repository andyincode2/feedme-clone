# URL → Markdown 변환 후 LLM으로 넘기기

웹 페이지 URL을 붙여넣으면 본문만 Markdown으로 뽑아 보여 주고, 복사·다운로드하거나 프롬프트를 붙여 ChatGPT·Claude로 바로 넘긴다.

## 연결된 소스

- [prototype.html](prototype.html): 승인된 화면. 화면 구성, 상태별 모습(빈 화면, 변환 중, 결과 3종, 오류 3종), 내보내기 영역의 배치(본문 위 패널, A안), 문구를 이 파일이 정한다. 이 스펙의 수용 기준은 동작을 정하고, 배치와 문구는 프로토타입을 따른다.
- [docs/decisions/ui-composition.md](../../decisions/ui-composition.md): 일반 UI는 shadcn/ui 컴포넌트와 semantic token으로 구성한다.
- [docs/decisions/dependency-versions.md](../../decisions/dependency-versions.md): 새로 들이는 의존성의 버전 범위 규칙.

## 사용자가 얻는 것

- URL 하나만 붙여넣으면 광고·메뉴가 빠진 본문을 Markdown으로 받는다.
- 결과를 읽어 보고 제목과 저자로 맞는 페이지인지 확인할 수 있다.
- 한 번의 클릭으로 Markdown을 복사하거나 `.md` 파일로 내려받는다.
- "요약해줘" 같은 프롬프트를 골라 ChatGPT나 Claude 새 탭으로 바로 넘긴다. 글이 길어도 잘리지 않는다.
- 라이트/다크 모드를 고를 수 있다.

## 범위

단일 화면 하나에 아래 흐름이 모두 들어간다.

1. **입력**: URL 입력칸, 변환 버튼, 입력값이 있을 때만 보이는 지우기(✕) 버튼.
2. **변환**: 서버가 페이지 HTML을 가져와 defuddle로 본문을 Markdown으로 추출한다.
3. **결과 확인**: 제목, 메타 줄(저자 · 게시일 · 사이트 · 글자 수), 렌더링된 Markdown 본문.
4. **내보내기**: 복사하기, `.md` 다운로드, 프롬프트 선택, ChatGPT로 열기, Claude로 열기.
5. **다크 모드 토글**: 헤더 오른쪽 아이콘 버튼.

## 수용 기준

### 입력과 리셋
- URL 입력칸에 값이 있으면 ✕ 버튼이 보이고, 비어 있으면 보이지 않는다.
- ✕를 누르면 입력값, 결과(또는 오류), 프롬프트 선택, 직접 입력 내용이 모두 사라지고 처음 빈 화면으로 돌아가며 입력칸에 포커스가 간다.
- Enter 또는 변환 버튼으로 변환을 시작한다.

### 변환
- `http://` 또는 `https://`로 시작하지 않는 값을 변환하면 서버에 요청하지 않고, 입력칸 아래에 "http:// 또는 https://로 시작하는 웹 페이지 주소를 입력해 주세요."를 보여 주며 입력칸을 오류 상태로 표시한다.
- 변환하는 동안 변환 버튼은 비활성화되고 "변환 중…"으로 바뀌며, 결과 자리에 스켈레톤이 보인다.
- 본문 추출은 defuddle 라이브러리로 한다. 예를 들어 `https://stephango.com/saw`를 변환하면 제목 "Use the saw, fear the saw", 저자 "Steph Ango"가 나온다.
- 페이지를 가져오지 못하면(네트워크 오류, 4xx/5xx 응답) "페이지를 가져오지 못했습니다" 오류와 "다시 시도" 버튼을 보여 준다. 다시 시도를 누르면 같은 URL로 다시 변환한다.
- 가져오기는 성공했지만 추출된 본문이 비어 있으면 "추출할 본문을 찾지 못했습니다" 안내를 보여 준다.
- 새 변환을 시작하면 이전 결과나 오류는 사라진다.

### 결과 확인
- 카드 맨 위에 페이지 제목을 보여 준다.
- 제목 아래 메타 줄에 저자, 게시일, 사이트, 글자 수를 점(·)으로 구분해 보여 준다. 값이 비어 있는 항목은 줄에서 빠진다. 예를 들어 저자가 없으면 저자 자리가 통째로 없어진다.
- 본문은 Markdown을 렌더링해 보여 준다. 제목(h2/h3), 목록, 표, 인용, 인라인 코드, 코드 블록, 링크가 서식대로 보인다.

### 내보내기
- **복사하기**를 누르면 Markdown을 클립보드에 복사하고 "Markdown을 클립보드에 복사했습니다" 토스트를 띄운다. 버튼은 잠시 "복사했습니다"로 바뀐다.
- **.md 다운로드**를 누르면 Markdown을 `.md` 파일로 내려받는다. 파일 이름은 페이지 제목에서 만든다.
- 복사와 다운로드에는 프롬프트가 붙지 않는다.

### 프롬프트
- 프리셋 칩 3개("요약해줘", "한국어로 번역해줘", "쉽게 설명해줘")와 "직접 입력" 칩이 있다. 한 번에 하나만 고를 수 있다.
- 고른 칩을 다시 누르면 선택이 풀리고, 아무것도 고르지 않으면 프롬프트 없이 본문만 넘어간다.
- "직접 입력"을 고르면 텍스트 입력칸이 나타나 포커스를 받는다. 다른 칩을 고르거나 선택을 풀면 입력칸이 사라지고 내용도 지워진다.
- 직접 입력한 프롬프트는 어디에도 저장하지 않는다. 새로고침하거나 새 변환을 하면 사라진다.
- 새 페이지를 변환하면 프롬프트 선택은 초기화된다.

### ChatGPT·Claude로 열기
- 넘기는 내용은 `프롬프트 + 빈 줄 + Markdown`이다. 프롬프트가 없으면 Markdown만 넘긴다.
- 넘기는 내용이 **4,000자 이하**이면 새 탭에서 ChatGPT(`https://chatgpt.com/?q=…`) 또는 Claude(`https://claude.ai/new?q=…`)를 열고, URL 인코딩한 내용을 입력창에 채운다.
- 넘기는 내용이 **4,000자를 넘으면** 그 내용을 클립보드에 복사한 뒤, 고른 LLM의 새 대화 화면(`https://chatgpt.com/`, `https://claude.ai/new`)을 새 탭으로 열고 "입력창에 붙여넣어(Ctrl+V) 보내세요" 토스트를 띄운다.
- 4,000자를 넘는 상태에서는 LLM 버튼 아래에 "본문이 길어 클립보드로 전달된다"는 안내가 버튼을 누르기 전부터 보인다. 프롬프트를 바꿔 길이가 기준을 넘나들면 안내도 즉시 나타나거나 사라진다.
- "직접 입력"을 골랐는데 내용이 비어 있으면 탭을 열지 않고, 입력칸에 포커스를 준 뒤 비어 있다고 안내한다.

### 다크 모드
- 헤더의 아이콘 버튼으로 라이트와 다크를 오간다. 아이콘은 라이트일 때 달, 다크일 때 해다.
- 다크 모드는 프로젝트의 기존 `.dark` 토큰으로 칠한다. 색을 화면에서 따로 지정하지 않는다.

### 반응형
- 휴대폰 너비(약 390px)에서는 URL 입력칸과 변환 버튼이 위아래로 쌓이고, 내보내기 버튼도 숨겨지지 않은 채 줄바꿈된다.

## 정해진 제약과 근거

- **본문 추출은 defuddle로 한다.** 사용자가 정한 필수 조건이다.
- **페이지 가져오기와 추출은 서버에서 한다.** 브라우저에서 다른 사이트의 HTML을 직접 가져오면 CORS에 막힌다.
  - 확인한 사실: `defuddle@0.19.6`과 `linkedom@0.18.15`를 이 프로젝트 사본(Next.js 16.4.5, Turbopack, `bun --bun run dev`)의 route handler에서 실행했다. 문서가 요구한다는 `"type": "module"` 설정 없이도 제목·저자·Markdown이 정상으로 나왔다.
  - 예시 결과: example.com은 저자가 빈 문자열, 한국어 위키백과 "마크다운" 문서는 30,237자였다.
  - 다시 검토할 때: defuddle 메이저 버전이 Node용 진입점(`defuddle/node`)이나 DOM `Document` 입력 방식을 바꾸면 이 확인을 다시 한다.
  - 새 의존성(defuddle, DOM 구현)은 dependency-versions 결정대로 caret 범위로 둔다.
- **LLM 전달은 "짧으면 URL, 길면 클립보드"다.** 사용자가 확인했다.
  - 근거: 두 서비스 모두 `?q=` 길이 한도를 공식 문서로 밝히지 않는다. Claude 데스크톱 딥링크는 약 14,000자에서 자른다고 안내하고, ChatGPT는 확인되지 않는다. 그래서 보수적인 4,000자를 기준으로 삼아, 긴 글도 잘리지 않게 했다.
- **UI는 ui-composition 결정을 따른다.** Button, Input, ToggleGroup, Card, Alert, Skeleton, Sonner(토스트), Empty는 shadcn/ui 공식 컴포넌트를 쓴다.
- **내보내기 영역은 제목과 본문 사이(A안)에 둔다.** 사용자가 하단 고정 바(B)와 오른쪽 사이드 패널(C)과 비교한 뒤 골랐다.

## 가정 (바꿔도 되는 기본값)

- 앱 이름과 헤더 로고는 "FeedMe"다.
- 복사·다운로드·LLM 전달에 쓰는 Markdown은 추출된 본문이다. 맨 위에 `# 제목`과 출처 URL 한 줄을 붙여, 넘겨받은 쪽이 어떤 글인지 알 수 있게 한다.
- `.md` 파일 이름은 제목에서 파일 이름에 쓸 수 없는 문자를 빼고 공백을 `-`로 바꿔 만든다. 제목이 비어 있으면 도메인을 쓴다.
- 메타 줄의 글자 수는 넘길 Markdown의 길이다. 클립보드로 넘어가는 이유를 짐작할 수 있게 하려는 표시다.
- 다크 모드는 처음에 시스템 설정을 따르고, 사용자가 고른 값은 이 브라우저에 기억한다.
- 빈 화면에는 짧은 글과 긴 글 예시 URL 버튼을 둔다. 누르면 그 URL로 바로 변환한다.
- 화면 아래에 "입력한 URL과 프롬프트는 저장하지 않습니다"를 표시한다.

## 범위 밖

- **보안 하드닝**(SSRF 방어, 요청 횟수 제한, 응답 크기 제한 등): AGENTS.md의 검증 예산이 스펙에 없는 하드닝을 범위 밖으로 정했다. 이 위험은 아래 "남은 위험"에 적었다.
- **JavaScript로만 본문을 그리는 페이지의 렌더링**(headless 브라우저 사용): 서버는 받은 HTML만 추출한다.
- **defuddle.md 호스팅 API**: 사용자가 라이브러리 사용을 정했다. 호스팅 API는 요청 수가 제한되고 키가 필요하다.
- **로그인, 변환 기록, 프롬프트 저장, 서버 측 캐시**: 직접 입력 프롬프트는 1회용으로 정해졌다.
- **ChatGPT·Claude 말고 다른 LLM**, 그리고 프롬프트 프리셋 편집 기능.

## 남은 위험

- **SSRF**: 서버가 사용자가 준 아무 URL이나 가져온다. 공개 배포하면 내부망 주소를 조회하는 데 악용될 수 있다. 범위 밖으로 둔 결정이므로, 외부에 공개하기 전에 다시 판단해야 한다.
- **`?q=` 동작이 바뀔 수 있다.** `chatgpt.com/?q=`와 `claude.ai/new?q=`는 공식 문서에 웹 주소로 나와 있지 않다. 동작이 바뀌거나 페이지가 열리자마자 바로 전송될 수 있다. ChatGPT의 실제 길이 한도도 확인되지 않았다.
- **본문을 못 뽑는 사이트가 있다.** 봇을 막는 사이트(403)나 JavaScript로만 그리는 페이지에서는 "가져오기 실패" 또는 "본문 없음"이 나온다.
- **실행 환경**: 이 컨테이너의 Node는 18.19.1이고, Next.js 16은 Node 20.9 이상을 요구한다. 지금은 `bun --bun run dev`로만 개발 서버가 뜬다. `bun run dev`나 `npm run dev`는 실패한다.
- **프로토타입 검증 범위**: 프로토타입은 linkedom DOM 테스트로 상호작용만 확인했고, 실제 브라우저 렌더링(레이아웃, 390px 화면, 다크 색상)은 확인하지 못했다. 구현 단계의 런타임 검증에서 처음 확인하게 된다.
